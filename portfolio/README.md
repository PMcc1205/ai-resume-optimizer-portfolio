# AI 简历优化助手｜公开作品集

> 一款面向校招、实习与应届求职者的 JD 驱动型简历优化工具。
>
> 作品集重点展示：问题定义、产品机制、AI 安全边界、真实端到端演示，以及可复现的评测迭代。

## 项目概述

把“根据 JD 改写简历”拆成一条可解释、可追溯、可由用户确认的链路：

`岗位要求 → 真实事实 → 证据映射 → 匹配状态 → 缺口诊断 → 事实约束改写 → 生成后校验 → 用户决策`

## 项目概览

| 项目项 | 内容 |
| --- | --- |
| 项目名称 | AI 简历优化助手 |
| 项目角色 | 用户研究、需求定义、AI 产品机制设计、原型与真实演示落地、AI 评测与迭代 |
| 目标用户 | 正在准备校招、实习或应届求职，并需要针对具体 JD 优化简历的求职者 |
| 研究输入 | 6 名目标用户访谈；47 份问卷回收，其中 42 份有效 |
| 评测结果 | 61 条冻结案例；通过率从 57.38% 提升至 81.97%，提升 24.59 个百分点 |
| 演示形态 | React + TypeScript 真实端到端 Demo；支持 JD 分析、事实确认、匹配、诊断、改写、校验与结果合并 |
